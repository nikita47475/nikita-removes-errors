API ключи

API-токен нужен внешнему ИИ или другой платформе, чтобы обращаться к этому сервису программно.

Не вставляйте реальный GitHub PAT в браузер, HTML или публичный репозиторий. Этот проект хранит токены сервиса в виде хэша.

  





  

    
Для роботов и ИИ

    
API возвращает JSON. Для загрузки проекта используется multipart/form-data. Для вставленного кода возвращается список ошибок и поле corrected_code.

    
Authorization: Bearer npa_…
POST /api/check
platform=auto|windows|linux|macos
upload=<ZIP или файл>
code=<текст, если файл не загружается>
