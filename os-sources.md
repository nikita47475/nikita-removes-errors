# Official operating-system sources

Use official/vendor sources for installers and recovery media.

- Microsoft software download center: https://www.microsoft.com/software-download/
- Apple macOS download/install support: https://support.apple.com/102662
- Ubuntu releases: https://releases.ubuntu.com/
- Ubuntu old releases: https://old-releases.ubuntu.com/releases/

This repository intentionally does not bundle operating-system images. Put any locally obtained test image into `os_images/` and connect it to a real VM/runner you control.
